# DRG 게임 기획서 v1.0

## 1. 게임 개요
- 게임명: DRG
- 장르: 전략 / 동시 행동 턴제 / 심리전
- 플랫폼: PC
- 엔진: Unity
- 최대 인원: 8명
- 초기 목표: 인간 1명 + AI 봇 프로토타입
- 장기 목표: 온라인 멀티플레이

### 핵심 콘셉트
모든 플레이어가 동시에 행동을 선택하고, 다른 플레이어의 선택은 공개되지 않는다. 모든 플레이어가 Lock하면 행동을 동시에 공개하고 결과를 처리한다.

핵심 재미는 행동 상성 자체보다 **상대가 다음에 무엇을 할지 예측하는 심리전**에 있다.

## 2. 핵심 게임 루프
```text
턴 시작 → 행동 선택 → Lock → 전원 Lock → 행동 공개 → 동시 해결 → HP/Ki 갱신 → 탈락 처리 → 승리 확인 → 다음 턴
```

살아있는 플레이어가 1명만 남으면 승리한다. 모든 플레이어가 동시에 사망하는 경우의 무승부 규칙은 후속 기획에서 확정한다.

## 3. 기본 능력
| 항목 | 기본값 |
|---|---:|
| HP | 3 |
| 최대 HP | 3 |
| Ki | 0 |
| 최대 Ki | 3 |

## 4. 행동
### 기 모으기
- Ki +1
- Ki가 3이면 사용 불가

### 에너지파
- Ki 1 소모
- 살아있는 상대 1명에게 1 데미지
- A→B, B→A인 경우 두 공격 모두 상쇄되며 양쪽 모두 데미지 없음
- 둘 다 C를 공격하는 경우 상쇄되지 않음

### 방어
- 비용 없음
- 자신을 대상으로 한 모든 에너지파 방어
- 원기옥은 방어하지 못함

### 순간이동
- Ki 1 소모
- 해당 턴 자신을 대상으로 한 모든 공격 회피
- 에너지파와 원기옥 모두 회피

### 원기옥
- Ki 3 소모
- 살아있는 상대 1명에게 1 데미지
- 방어 무시
- 에너지파와 상쇄되지 않음
- 순간이동으로만 회피 가능

## 5. 행동 상호작용
| 공격 | 대상 행동 | 결과 |
|---|---|---|
| 에너지파 | 기 모으기 | 적중 |
| 에너지파 | 에너지파 | 서로 직접 공격한 경우 상쇄 |
| 에너지파 | 방어 | 방어 |
| 에너지파 | 순간이동 | 회피 |
| 에너지파 | 원기옥 | 독립적으로 적중 |
| 원기옥 | 기 모으기 | 적중 |
| 원기옥 | 방어 | 적중 |
| 원기옥 | 순간이동 | 회피 |
| 원기옥 | 원기옥 | 독립적으로 적중 |

여러 플레이어가 한 명을 동시에 공격할 수 있으며 데미지는 누적된다.

## 6. 동시 행동 원칙
한 턴에 Lock한 행동은 해당 턴에 이미 확정된 행동이다. 해결 도중 HP가 0이 되어도 이미 선택한 행동은 처리한다.

예:
```text
A → B
B → C
C → A
```
A가 먼저 사망해도 A의 C 공격은 해당 턴에 처리한다.

다음 턴부터 탈락 플레이어는 행동하지 않는다.

## 7. 전략 목표
- 상대의 행동 예측
- 공격 대상 예측
- Ki 관리
- 방어/순간이동 타이밍
- 원기옥을 위한 위험 감수
- 여러 플레이어 사이에서 누구를 견제할지 판단

## 8. 정보 공개
공개: 닉네임, 생존 여부, HP, Ki, 자신의 행동, Lock 여부.

비공개: 행동 선택 단계에서 상대가 선택한 실제 행동.

모든 살아있는 플레이어가 Lock한 후 상대 행동을 공개한다.

## 9. 탈락
- HP가 0 이하이면 탈락
- 탈락 플레이어는 관전
- 이후 턴에는 행동 불가
- 이미 Lock한 현재 턴 행동은 처리
- 탈락 플레이어는 이후 대상이 될 수 없음

## 10. 게임 진행
```text
Start → Lobby → Room → Character Select → Ready → Game → Result
```
프로토타입에서는 인간 1명 + AI 최대 7명을 지원한다. 모든 참가자가 Ready이고 방장이 시작하면 게임을 시작한다.

## 11. 캐릭터
초기 프로토타입은 기본 캐릭터 1개, 특수 능력 없음. 이후 HP/Ki/패시브/고유 행동 등을 ScriptableObject 기반으로 확장한다.

## 12. AI
AI도 인간과 동일한 PlayerAction을 생성한다.
- Ki 낮음 → Gather
- Ki 1~2 → Energy Wave/Gather
- Ki 3 → Spirit Bomb/Energy Wave
- HP 낮음 → Block/Teleport 확률 증가
향후 Easy/Normal/Hard로 확장한다.

## 13. 이모트
턴 행동을 소비하지 않고 밸런스에 영향을 주지 않는다.
예: 인사, 도발, 박수, 웃음, 화남.

## 14. 플레이어 기록
Player ID, 닉네임, 총 게임 수, 승리 수, 패배 수. 프로토타입은 로컬 JSON 저장을 사용할 수 있다.

## 15. 프로토타입 목표
```text
Lobby → AI 추가 → Game Start → Turn → Action Select → Lock → Resolve → HP/Ki Update → Elimination → Winner → Result → Lobby
```

## 16. 기획 검증 포인트
- 50판 이상 플레이해도 새로운 판단이 발생하는가?
- 8인이 실제로 상호작용하는가?
- Block/Teleport가 지나치게 강하지 않은가?
- 게임이 무한히 길어지지 않는가?
- 평균 플레이 시간이 적절한가?
- 탈락 후 기다리는 시간이 과도하지 않은가?
- 공격 대상 선택에 전략적 의미가 있는가?

## 17. 사전 플레이테스트
Unity 구현 전에 2~8인이 종이/콘솔로 플레이한다.
검증 항목:
- 행동 상성의 직관성
- 특정 행동의 과도한 강함
- 원기옥 사용 빈도
- 평균 게임 턴
- 공격 대상 선택의 의미
- 사망 시 자신의 판단과 결과가 연결되는지
