# M3 플레이 체크리스트 (Human vs BotAI)

- 대상 빌드: `build4/DRG.exe` (DevLog 11, M3 BotAI 포함)
  - 처음 대상이던 `build3`은 임시 폴더와 함께 지워졌다.
  - M4부터는 시작할 때 설정 패널이 나온다. 이 체크리스트는 **봇 1명**을 골라 2인전으로 진행한다.
  - 다인전 봇 행동은 `UI_수동_테스트_케이스.md`의 UI-35에서 확인한다.
- 목적: BotAI로 바꾼 뒤 한 판을 끝까지 문제없이 할 수 있는지, 봇이 규칙대로 행동하는지 확인한다. 결과는 M3 완료 판정 근거가 된다.
- 기준 문서: 기획서 §12 AI, 명세서 §20·§24 STEP 7, `DECISIONS.md` DEC-008, `Assets/_Project/Scripts/AI/BotAI.cs`
- 권장 분량: 10~20판. 봇 행동은 확률이라 여러 판을 해야 규칙에서 벗어난 행동이 보인다.

## B. 봇 행동 규칙 (DEC-008)
공개(Reveal) 후 봇 카드의 `Action:`과 로그로 확인한다. "절대"라고 적은 항목은 한 번이라도 어기면 **실패**다.

| ID | 봇 상태 | 기대 결과 | 결과 | 관찰 횟수/메모 |
|---|---|---|---|---|
| M3-B01 | Ki 0, HP 2~3 | **항상** Gather | | |
| M3-B02 | Ki 1~2, HP 2~3 | Energy Wave 또는 Gather만. 대략 반반 | | |
| M3-B03 | Ki 3, HP 2~3 | Spirit Bomb 또는 Energy Wave만. 대략 반반 | | |
| M3-B04 | HP 2~3 (Ki 무관) | **절대** Block이나 Teleport를 쓰지 않음 | | |
| M3-B05 | HP 1, Ki 0 | Block 또는 Gather만. Block은 가끔(약 40%) | | |
| M3-B06 | HP 1, Ki 1~2 | Block·Teleport·Energy Wave·Gather 중 하나. 방어(Block+Teleport)는 가끔(약 40%) | | |
| M3-B07 | HP 1, Ki 3 | Block·Teleport·Spirit Bomb·Energy Wave 중 하나 | | |
| M3-B08 | 모든 상태 | **절대** 불가능한 행동을 하지 않음 (Ki 부족 공격, Ki 3에서 Gather, 로그에 `action failed`) | | |
| M3-B09 | 공격할 때 | 대상이 항상 나(You). 2인전이라 살아 있는 상대는 나뿐이다 | | |

비율(반반, 40%)은 몇 판으로 정확히 판단할 수 없다. 한쪽으로 크게 치우쳐 보이면 메모만 남긴다. 정확한 비율은 `BotAITests`가 2,000회 추출로 확인한다.

## D. 체감 질문 (기획서 §16·§17)
정답은 없다. 느낀 대로 적는다. 규칙을 바꿀지는 소유자가 정한다.

| 질문 | 답 |
|---|---|
| 봇이 "생각하는 것처럼" 보이는가, 아니면 기계적으로 보이는가? | |
| 봇의 다음 행동을 예측하고 맞히는 재미가 있는가? (예: "Ki 0이면 무조건 모은다"를 알아채면 너무 쉬워지는가) | |
| HP가 2~3인 봇이 한 번도 방어하지 않는 것이 어색한가? | |
| 한 판에 걸린 턴 수와 시간 (판마다 기록) | |
| 너무 길거나 지루한 순간이 있었는가? (무한 반복 느낌) | |
| Block / Teleport가 너무 강하거나 약하게 느껴지는가? | |
| Spirit Bomb을 얼마나 자주 썼고, 쓸 만했는가? | |
| 졌을 때 "내 판단 때문에 졌다"고 느껴지는가? | |
