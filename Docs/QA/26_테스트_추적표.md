## 행동 조합표 (§26 #2)
두 플레이어가 서로 다른 행동을 할 때의 조합이다. 공격은 상대를 노린다고 본다. 칸에는 이 조합을 직접 확인하는 `BattleResolver` 테스트를 적었다.

| | Gather | Energy Wave | Block | Teleport | Spirit Bomb |
|---|---|---|---|---|---|
| **Gather** | `AlreadyEliminatedPlayer_IsSkipped` (간접) | `EnergyWave_OnGather_Hits` | `Gather_AddsOneKi` | **없음** | `SpiritBomb_OnGather_Hits` |
| **Energy Wave** | | `EnergyWave_Mutual_BothCancelled_NoDamage_KiStillSpent` | `EnergyWave_OnBlock_IsBlocked_AndKiIsStillSpent` | `EnergyWave_OnTeleport_IsDodged_AndKiIsStillSpent` | `EnergyWave_And_SpiritBomb_AtEachOther_BothHit` |
| **Block** | | | `Block_CostsNoKi` | `Teleport_CostsOneKi` | `SpiritBomb_IgnoresBlock` |
| **Teleport** | | | | **없음** | `SpiritBomb_OnTeleport_IsDodged` |
| **Spirit Bomb** | | | | | `SpiritBomb_Mutual_DoesNotCancel_BothHit` |

- 없음 2칸(Gather+Teleport, Teleport+Teleport)은 공격이 없는 조합이다. 각자 Ki만 바뀌므로 위험은 낮다. 각 행동의 Ki 변화는 #1에서 따로 확인된다.
- Gather+Gather는 `AlreadyEliminatedPlayer_IsSkipped` 등에서 준비용으로 쓰이지만, 두 사람의 Ki가 모두 +1인지 확인하는 테스트는 없다.
