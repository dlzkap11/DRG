## 내용
### UI 수동 테스트 케이스
- **M4 때문에 바뀐 기존 케이스**:
  - UI-01: 시작할 때 설정 패널에서 봇 1명을 고른다.
  - UI-10: 공개 패널은 판정 결과만 보여주고, Skip to End는 숨겨진다.
  - UI-18: Play Again을 누르면 설정 패널로 돌아간다.
- **새 케이스 16개**:

| 묶음 | 케이스 | 주요 확인 내용 |
|---|---|---|
| I. 설정 패널 | UI-25~29 | 시작 화면, 봇 수 선택 강조, N명으로 시작하면 카드 N+1장, Play Again 후 선택 유지, Start 연타 |
| J. 다인전 화면 | UI-30~35 | 8장 한 줄, 대상 7개, **탈락한 봇이 대상에서 빠짐**, 카드·공개 패널·로그 일치, 판정 줄이 많을 때 배치, 봇 대상 분산 |
| K. 관전 | UI-36~40 | 관전 표시, Next Turn으로 봇끼리 진행, Skip to End로 종료하고 로그 누락 없음, 생존 중 Skip 숨김, Skip 연타 |

- 각 케이스에 관련 자동 테스트 이름을 적었다. 이름은 M4 브랜치의 실제 테스트 이름과 대조했다.
- 자동 테스트가 없는 케이스(UI-28, 29, 32, 34, 40과 배치 확인)가 수동 확인의 핵심이다.
- 2인 화면 기준으로 남겨 두었던 "M4에서 추가" 메모 3개는 UI-30·32·36~38로 옮기고 삭제했다.

## 검증
- 문서만 바꿨으므로 Unity 테스트는 다시 실행하지 않았다.
  - 참조한 M4 테스트 수 137개와 통과 여부는 DevLog 11의 실행 결과다.
- 새 케이스가 참조하는 자동 테스트 이름 12개를 M4 브랜치 테스트 코드와 하나씩 대조했다.
- 화면 문구(`You are eliminated - spectating`, `No attacks this turn.`, `Skip to End` 등)를 M4 코드와 대조했다.
