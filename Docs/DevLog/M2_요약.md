## 한 줄 요약
사람 1명이 봇 1명과 **실제 게임 화면에서 한 판을 끝까지** 플레이할 수 있게 되었다.
- 행동 선택, 대상 선택, Lock, 공개, 전투 로그, 승패, 다시 하기가 모두 동작한다.
- 게임 로직은 M1 코드를 그대로 쓴다.

## 1. 구현한 구조
```text
[UXML 버튼] → BattleView (Lock 전 임시 선택만 보관)
            → LocalBattleSession.SubmitHumanAction ──→ TurnManager.Lock (ActionValidator)
BotPlayer (RandomActionPolicy, 임시) ──────────────→ TurnManager.Lock   ← 사람과 같은 경로
전원 Lock → TurnManager.StartResolution → BattleResolver → BattleResult
          → BattleView.Refresh (카드, 공개 패널, 로그, 게임 종료)
```

| 구성 요소 | 역할 | 위치 |
|---|---|---|
| `LocalBattleSession` | 사람 1명 + 봇 N명으로 한 판을 진행. UI가 요청하는 유일한 창구. 공개 전 상대 행동 숨김 | `Scripts/Core` |
| `BotPlayer` | 봇 자리. 사람과 같은 `PlayerAction`을 만든다. 지금은 `RandomActionPolicy` 사용 | `Scripts/AI` |
| `BattleView` | UXML 요소와 세션 연결 (순수 C#, 테스트 가능) | `Scripts/UI` |
| `BattleScreen` | 씬 진입점 MonoBehaviour (세션 생성, 다시 하기) | `Scripts/UI` |
| `BattleLogFormatter` | `BattleResult`를 로그 문장으로 변환 | `Scripts/UI` |
| `BattleScreen.uxml` / `.uss` | 화면 구조와 스타일 | `UI/` |
| `DRGRuntimeTheme.tss`, `DRGPanelSettings.asset` | UI Toolkit 기본 테마, 1280×720 기준 크기 조정 | `UI/` |
| `GameScene.unity` | 카메라 + BattleScreen(UIDocument). 빌드 목록 첫 번째 | `Scenes/` |
| `GameSceneBuilder` | 씬과 PanelSettings 자동 생성 (메뉴 `DRG > Build Game Scene`) | `Editor/` |

- 모든 경로는 `Assets/_Project/` 아래에 있다.
- 게임 로직과 화면 코드는 `DRG.Runtime`, 에디터 도구는 `DRG.Editor`, 테스트는 `DRG.Tests.EditMode` 어셈블리에 있다.

**지킨 원칙**
- **Human과 Bot 통합**: 둘 다 `PlayerAction`을 만들어 `TurnManager.Lock`으로 확정한다. 전투 코드에는 사람인지 봇인지 구분하는 분기가 없다.
- **UI는 게임 상태를 바꾸지 않음**: UI가 들고 있는 것은 "고른 행동과 대상" 같은 Lock 전 임시 선택뿐이다. HP, Ki, 행동 확정은 모두 세션을 거쳐 게임 로직이 처리한다.
- **연출은 결과를 보여주기만 함**: 판정은 `BattleResolver`가 끝낸 결과를 텍스트로 보여줄 뿐 다시 계산하지 않는다.

## 2. 구현된 기능
- **플레이어 카드**: 이름, HP, Ki, 상태(Choosing / Locked / Eliminated), 행동
- **정보 공개 규칙** (기획서 §8): 공개 전 상대 행동은 "? (hidden)"으로 표시된다. 세션은 공개 전에는 `null`을, 공개 후에는 복사본을 돌려준다.
- **행동 버튼**: 쓸 수 있는 행동만 켜진다(`ActionValidator` 기준). Lock할 때 게임 로직이 다시 검증한다.
- **공격 흐름**: 행동을 고르면 대상 패널이 나오고(상대만 표시), 대상을 골라야 Lock이 켜진다.
- **턴 흐름**:
  1. 봇이 먼저 Lock한다. 봇의 행동은 숨겨진다.
  2. 사람이 Lock하면 바로 전투를 처리하고 결과를 공개한다.
  3. "Next Turn" 버튼으로 다음 턴을 시작한다.
- **전투 로그**: 최근 턴부터 표시된다. 형식은 "Energy Wave You -> Bot 1: Hit", "Eliminated: Bot 1", "Winner: You"이다.
- **게임 종료**: "You win!" / "Bot 1 wins. You lose." / "Draw - no survivors." 중 하나를 표시하고, 행동 입력 줄을 숨기고, "Play Again"으로 새 게임을 시작한다.
- **입력**: 프로젝트는 Input System만 사용하도록 설정돼 있다. UI Toolkit이 EventSystem 없이 입력을 받는다.
