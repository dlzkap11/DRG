# 00. 저장소 초기화

- 날짜: 2026-09-28
- 커밋: `c6b328e` Initial commit: Unity project and DRG Claude Code harness

## 목표
로컬 프로젝트를 Git으로 관리하고 GitHub 저장소와 연결한다.

## 변경한 파일
- `.gitignore`: Claude 로컬 설정 항목은 그대로 두고 Unity 표준 제외 항목을 추가했다.
  - Unity 자동 생성 폴더: `Library/`, `Temp/`, `Obj/`, `Build(s)/`, `Logs/`, `UserSettings/`, `MemoryCaptures/`, `Recordings/`
  - IDE와 자동 생성 파일: `.vs/`, `.idea/`, `*.csproj`, `*.sln`, `*.slnx` 등
  - 빌드 결과물과 OS 파일: `*.apk`, `*.unitypackage`, `.DS_Store`, `Thumbs.db` 등

## 작업 내용
- `git init -b main`으로 저장소를 만들고 첫 커밋을 했다.
- GitHub Public 저장소 https://github.com/dlzkap11/DRG 를 `origin`으로 연결하고 `main`을 push했다.
  - 저장소는 사용자가 직접 만들었다.

## 검증
- 첫 커밋 전에 staged 목록을 확인했다. 약 2GB인 `Library/`와 `Logs/`, `UserSettings/`, `.csproj`는 포함되지 않았다.
- `git status`에서 커밋 안 된 변경이 없었다.
- `main`이 `origin/main`을 추적하는 것을 확인했다.
- `git ls-remote`로 원격 HEAD가 `c6b328e`인 것을 확인했다.

## 참고
- Git LFS 3.7.1이 설치돼 있지만 아직 설정하지 않았다. 큰 바이너리 에셋이 생기면 설정을 검토한다.
