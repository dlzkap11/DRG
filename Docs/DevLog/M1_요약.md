## 한 줄 요약
UI 없이 순수 C#만으로 **동시 행동 턴제 전투를 한 판 끝까지** 돌릴 수 있게 되었다. 자동 테스트 79개로 규칙을 확인했다.

## 1. 구현한 구조
```text
Human / Bot (M2 이후)
    ↓  PlayerAction
TurnManager ── Lock할 때 ActionValidator로 검증
    ↓  전원 Lock → StartResolution()
BattleResolver ── 모든 행동을 동시에 처리
    ↓
BattleResult ── 데미지, Ki 변화, 행동 결과, 탈락자, 승패
    ↓
BattlePresentation / UI (M2 이후)
```

| 클래스 | 역할 | 위치 |
|---|---|---|
| `GameSettings` | 모든 수치 기본값 (HP, Ki, 비용, 데미지, 최대 인원) | `Scripts/Core` |
| `GameState` | 화면 흐름 단계 (아직 사용하는 곳 없음) | `Scripts/Core` |
| `Player`, `PlayerState` | 플레이어 HP·Ki·생존 여부·이번 턴 행동 | `Scripts/Player` |
| `PlayerAction`, `ActionType` | 한 턴의 행동. Human과 Bot이 같은 형식을 씀 | `Scripts/Player` |
| `ActionValidator` | 행동이 규칙에 맞는지 검사, Ki 비용 계산 | `Scripts/Battle` |
| `TurnManager`, `TurnState`, `LockResult` | 턴 진행, Lock, 전원 Lock 확인, 탈락자 자동 Lock, 게임 종료 | `Scripts/Battle` |
| `BattleResolver` | 한 턴을 동시에 처리 (UI·애니메이션에 의존하지 않음) | `Scripts/Battle` |
| `BattleResult` 외 결과 타입 | 처리 결과 데이터 (`DamageResult`, `KiChangeResult`, `ActionResult`, `GameOutcome`) | `Scripts/Battle` |

- 모든 경로는 `Assets/_Project/` 아래에 있다.
- 게임 로직은 `DRG.Runtime` 어셈블리에, 테스트는 `DRG.Tests.EditMode` 어셈블리에 있다.

### 턴 진행 순서
```text
StartTurn → StartActionSelection (탈락자 자동 Lock) → Lock × 생존자 수
→ StartResolution (전투 처리, BattleResult 반환) → EndTurn → 다음 StartTurn
```
승리나 무승부가 나오면 `IsGameOver`가 `true`가 되고 다음 턴을 시작할 수 없다.

## 2. 구현된 전투 규칙
| 행동 | Ki | 효과 |
|---|---:|---|
| 기 모으기 | +1 | Ki가 3이면 사용 불가 |
| 에너지파 | -1 | 살아 있는 상대 1명에게 1 데미지 |
| 방어 | 0 | 자신을 겨눈 에너지파를 모두 막음. 원기옥은 못 막음 |
| 순간이동 | -1 | 자신을 겨눈 모든 공격을 회피 |
| 원기옥 | -3 | 살아 있는 상대 1명에게 1 데미지. 방어 무시, 상쇄되지 않음 |

**공격 판정 순서** (공격 하나마다 적용)
1. 대상이 순간이동 → **회피**
2. 원기옥 → **적중**
3. 에너지파이고, 대상이 정확히 이 공격자에게 에너지파를 쏨(A↔B) → **상쇄**
4. 에너지파이고 대상이 방어 → **막힘**
5. 그 외 → **적중**

**동시 처리 원칙**
- 판정은 Lock된 행동만 보고 HP는 보지 않는다. 그래서 처리 순서가 결과를 바꾸지 않는다.
- 이번 턴에 쓰러지는 플레이어의 행동도 그대로 적용된다. 예를 들어 A→B, B→C, C→A이고 모두 HP 1이면 셋 다 탈락한다.
- 여러 공격을 맞으면 데미지가 누적된다. A→C와 B→C는 상쇄되지 않는다.

## 3. 확정된 설계 결정
전문은 [DECISIONS.md](../DECISIONS.md)에 있다.

| 번호 | 결정 |
|---|---|
| DEC-001 | `None` 행동은 탈락자 자동 Lock 전용이다. 살아 있는 플레이어가 None을 내면 거부한다. |
| DEC-002 | 공격이 막히거나, 회피되거나, 상쇄돼도 Ki는 소모된다. |
| DEC-003 | HP는 0에서 멈춘다. 실제로 들어간 데미지는 `DamageResult`에 그대로 남는다. |
| DEC-004 | 생존자가 0명이면 무승부다. |
| DEC-005 | 전투 처리 중 잘못된 행동은 `Failed`로 기록하고 효과가 없다. Ki도 변하지 않고 방어 효과도 없다. |
| DEC-006 | `BattleResult`에 탈락자, 게임 결과, 승자 정보를 넣는다. |
