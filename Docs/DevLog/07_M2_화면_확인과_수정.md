## 발견한 문제와 수정
| # | 문제 | 원인 | 수정 |
|---|---|---|---|
| 1 | 활성 버튼(행동, 대상, Lock, Next Turn)의 글자가 밝은 회색 배경 위의 밝은 글자라 잘 안 보이고, 비활성 버튼과 구분이 어려움 | 기본 테마의 밝은 버튼 배경에 화면 전체의 밝은 글자색이 그대로 적용됨 | USS에서 버튼 배경과 테두리를 어두운 색으로 직접 지정. 마우스를 올리면 밝아지고, 비활성일 때는 `opacity 0.35`로 흐리게 표시 |
| 2 | 카드의 "Action: Energy Wave -> Bot 1"이 카드 폭을 넘어 테두리에 닿음 | 카드 폭 200px | 카드 폭을 260px로 늘리고, 행동 글자가 줄바꿈되게 함 |
| 3 | 게임이 끝나면 세로 공간이 부족해 Reveal 패널이 눌리고, 마지막 줄과 Play Again 버튼이 패널 밖으로 넘침 | 행동·Lock·Reveal·Game over 패널이 모두 표시되고, 패널이 공간에 맞춰 줄어듦 | 패널이 줄어들지 않게 함(`flex-shrink: 0`). 게임 종료 후에는 고를 것이 없으므로 행동 패널과 Lock 줄(`lock-row`)을 숨김 |
| 4 | 로그의 "You wins!", "You is eliminated." 문장이 어색함 | "{이름} wins!" 형식이라 사람 플레이어 이름 "You"와 문법이 맞지 않음 | "Winner: {이름}", "Eliminated: {이름}" 형식으로 변경 |

## 검증
- EditMode 테스트: **112개 중 112개 통과**, 컴파일 오류·경고 0건
  - 테스트 수는 그대로다. 기존 테스트에 확인 항목을 추가하고 로그 문구 기대값을 바꿨다.
- 수정본 Windows 빌드: `build2/DRG.exe`, `Build Finished, Result: Success`
  - 빌드할 때 Unity가 다시 저장한 관계없는 설정 파일 5개는 되돌렸다.
- **확인하지 못한 것**: 수정본(`build2`) 창에 대한 화면 접근 요청이 거부되어, 수정한 화면을 캡처로 다시 보지 못했다. 버튼 대비, 카드 폭, 게임 종료 화면 배치가 실제로 좋아졌는지는 눈으로 확인해야 한다.
