## 구현 내용과 설계 판단
- **세션은 거의 그대로**:
  - `LocalBattleSession`은 M2 때부터 봇 1~7명을 지원했다(생성자에서 범위를 검사함).
  - 사람이 탈락하면 `StartNextTurn`이 봇만으로 턴을 바로 처리하는 동작도 이미 있었다.
  - 이번에는 `IsHumanEliminated` 속성만 추가했다.
- **설정 패널**:
  - 봇 수 버튼은 `BattleView` 생성자가 `maxBotCount`(= `GameSettings.MaxPlayers - 1`)만큼 코드로 만든다. 그래서 UXML에 7을 직접 쓰지 않았다.
  - Start를 누르면 `StartRequested(botCount)` 이벤트가 나간다. `BattleScreen`이 그 수로 세션을 만들어 `Bind`한다.
  - 고른 봇 수는 게임 상태가 아니라 UI 선택값이다.
  - 씬의 `BattleScreen.botCount` 필드는 이름을 그대로 두었다. 이제 "설정 패널의 처음 선택값"을 뜻한다. 이름을 바꾸면 씬에 저장된 값이 끊긴다.
- **관전과 Skip to End**:
  - 사람이 탈락하면 행동 패널과 Lock 줄을 숨기고, 단계 문구를 "You are eliminated - spectating"으로 바꾼다.
  - 공개 패널에는 Next Turn과 Skip to End가 함께 나온다.
  - `SkipToEnd`는 세션의 기존 API(`StartNextTurn`)를 반복해서 부를 뿐이다. 게임 상태를 직접 바꾸지 않는다.
  - 턴마다 로그를 남긴다.
  - 무한 반복을 막기 위해 최대 1,000턴의 안전 한도를 두었다. BotAI 8인 시뮬레이션의 최대 턴은 59였다.
- **8인 배치**:
  - 카드는 `flex-grow: 1`, `min-width 120px`, `max-width 220px`이다. 2명이면 넓게, 8명이면 한 줄에 나뉘어 들어가도록 했다.
  - 글자 크기를 줄였다(이름 16, 내용 13).
  - 대상 버튼 최소 폭은 96px로 줄여 7개도 2줄 안에 들어가게 했다.
- **공개 패널 간결화**:
  - `FormatOutcomes`는 판정 결과(적중·막힘·회피·상쇄·실패), 탈락, 승자·무승부만 반환한다.
  - 공격이 없는 턴에는 "No attacks this turn."을 반환한다.
  - 전투 로그(`FormatTurn`)는 이전처럼 행동 줄까지 모두 남긴다. 공격이 없는 턴에 위의 문구를 붙이지 않는다.

## 검증
- EditMode 테스트: **137개 중 137개 통과** (기존 124 + 이번 13), 컴파일 오류·경고 0건
  - `BattleViewTests` (+8)
    - 공개 패널은 판정 결과만 표시
    - 새 화면은 설정 패널을 보여주고 봇 수 버튼은 7개
    - Bind하면 설정 패널이 숨겨짐
    - Start를 누르면 고른 봇 수로 이벤트가 나감(범위 밖 값은 무시)
    - Play Again을 누르면 설정 패널로 돌아감
    - 8인이면 카드 8장, 공격 대상 7명(자기 자신 제외)
    - 탈락하면 관전 표시가 나오고 Skip to End로 게임이 끝나며, 로그의 턴 수가 실제 턴 수와 같음
    - 살아 있는 동안에는 Skip 버튼이 숨겨짐
  - `LocalBattleSessionTests` (+3): 8인에서 봇 7명이 모두 Lock하고 행동이 숨겨짐, `IsHumanEliminated`, 8인 게임을 끝까지 진행
  - `BattleLogFormatterTests` (+2): `FormatOutcomes`가 판정 결과만 반환, 공격이 없으면 안내 문구
- Windows 플레이어 빌드: `build4/DRG.exe`, `Build Finished, Result: Success`
