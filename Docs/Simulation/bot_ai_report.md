# DRG 자동 시뮬레이션 리포트 (BotAI)

> 이 파일은 `DRG > Run Simulation` 메뉴 또는 `-executeMethod DRG.EditorTools.SimulationRunner.Run`으로 생성됩니다. 직접 수정하지 마세요.

## 설정
- 정책: 모든 자리가 BotAI(DEC-008) 규칙으로 행동한다. HP 1이면 40% 확률로 방어(Ki가 있으면 방어/순간이동 반반, Ki 0이면 방어), 그 외에는 Ki 0 기 모으기, Ki 1~2 에너지파/기 모으기 반반, Ki 3 원기옥/에너지파 반반. 공격 대상은 살아 있는 상대 중 무작위.
- 경로: 실제 `TurnManager` (Lock 검증) → `BattleResolver`
- 인원별 판 수: 1000, seed: 20260928, 턴 상한: 200 (시뮬레이션 안전장치이며 게임 규칙이 아님)

> **해석 주의**: 모든 자리가 같은 단순 규칙 봇이다. 상대의 행동을 예측하는 사람의 플레이와 다르므로, 이 수치는 턴 제한과 밸런스 논의의 참고 자료이지 결론이 아니다.
